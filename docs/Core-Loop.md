# Core Loop

## Purpose

The Core Loop defines the repeated cycle that creates progress, motivation, and continued engagement.

Every successful product has a repeatable loop.

The American Journey's loop should continuously move users toward integration, opportunity, and citizenship readiness.

---

# Primary Core Loop

Assess

↓

Learn

↓

Apply

↓

Advance

↓

Unlock

↓

Return

---

## Assess

The user evaluates their current readiness.

Examples:

* English Assessment
* Financial Literacy Assessment
* Citizenship Assessment

Output:

Current readiness score.

---

## Learn

The user completes lessons and learning activities.

Examples:

* English lessons
* Financial literacy lessons
* Citizenship lessons

Output:

Knowledge gained.

---

## Apply

The user applies knowledge in real life.

Examples:

* Open a bank account
* Improve English conversations
* Complete paperwork correctly

Output:

Practical progress.

---

## Advance

The user improves readiness scores and track progress.

Output:

Visible improvement.

---

## Unlock

The user earns:

* Badges
* Achievements
* New content
* New opportunities

Output:

Motivation.

---

## Return

The dashboard recommends the next action.

Examples:

* Complete next lesson
* Improve readiness score
* Unlock next milestone

Output:

Continued engagement.

---

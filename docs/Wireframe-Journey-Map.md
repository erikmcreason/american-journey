# Journey Map Wireframe

## Purpose

The Journey Map is the emotional center of The American Journey.

The Dashboard tells users what to do.

The Journey Map reminds them why they are doing it.

The Journey Map should create motivation, anticipation, and a sense of progress.

## Design Principles

The Journey Map should:

* Show progress
* Show future opportunities
* Create anticipation
* Reward effort
* Reduce uncertainty

Users should always understand:

* Where they are
* What comes next
* Why it matters

---

## Motivation System

Each stage should reveal future opportunities.

Users should be able to preview:

* Skills
* Certifications
* Opportunities
* Community roles
* Leadership pathways

before they unlock them.

The objective is to create curiosity and long-term engagement.

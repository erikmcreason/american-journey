# PRODUCT STRATEGY

## PURPOSE

This document defines the strategic principles used to guide product decisions for The American Journey.

The purpose of this document is to ensure future features, curriculum, partnerships, assessments, tools, and development efforts remain aligned with the long-term vision of the platform.

This document should be consulted before significant product decisions are made.

---

# CORE PRODUCT THESIS

The American Journey is not primarily an educational platform.

The American Journey is a success platform.

Education is a mechanism.

Success is the outcome.

The platform exists to help users improve:

* Economic Mobility
* Social Mobility
* Trust Capital
* Integration
* Self-Awareness
* Leadership
* Long-Term Contribution

---

# OUTCOME-FIRST DESIGN

Users rarely want information.

Users want outcomes.

Examples:

Users do not want:

* Credit lessons
* Tax lessons
* Citizenship lessons
* Resume lessons

Users want:

* Better jobs
* Higher income
* Housing stability
* Financial security
* Opportunity
* Success

Educational content should exist only when it helps produce meaningful outcomes.

---

# ECONOMIC MOBILITY STRATEGY

Economic mobility is one of the highest priorities of the platform.

Reason:

Economic instability makes many other forms of progress significantly more difficult.

Examples:

* Employment Readiness
* Resume Development
* Interview Preparation
* Professional Development
* Entrepreneurship
* Wealth Building

---

# SOCIAL MOBILITY STRATEGY

The platform should help users increase access to opportunity through relationships, networks, community participation, and leadership.

Examples:

* Professional Networking
* Communication Skills
* Community Involvement
* Leadership Development

---

# TRUST CAPITAL STRATEGY

Trust Capital is accumulated through:

* Reliability
* Integrity
* Accountability
* Civic Responsibility
* Consistency

Trust Capital accelerates both economic mobility and social mobility.

---

# ITALIAN IMMIGRANT THOUGHT EXPERIMENT

A recurring product design framework.

Question:

"If my grandparents arrived from Italy today, what would I want them to know?"

Use this framework when evaluating:

* Features
* Curriculum
* Tools
* Partnerships
* User Experience

---

# SUCCESS PATH STRATEGY

Not all users want the same destination.

Potential paths include:

* Stability Path
* Career Path
* Entrepreneurship Path
* Investor Path
* Community Leadership Path

Users should be able to stop when they reach their desired outcome or continue pursuing additional goals.

---

# PRODUCT DECISION FILTER

Future features should be evaluated using:

1. Does this improve economic mobility?
2. Does this improve social mobility?
3. Does this improve trust capital?
4. Does this improve integration?
5. Does this improve self-awareness?
6. Does this improve long-term success?
7. Does this improve contribution?
8. Does this create measurable outcomes?

Features satisfying multiple criteria should generally receive higher priority.

---

# GUIDING PRINCIPLE

The objective is not content completion.

The objective is transformation.

# The American Journey User Journey Map

## Stage 1: Arrival

The user discovers The American Journey.

Goals:
- Create account
- Select current status
- Complete onboarding assessment

Outputs:
- User profile
- Initial readiness score
- Personalized journey path

---

## Stage 2: Foundation

The user builds foundational skills.

Tracks:
- English & Communication
- Financial Literacy & Opportunity
- Administrative Readiness

Goals:
- Understand basic systems
- Avoid common mistakes
- Build confidence

Outputs:
- Foundation Badge
- Progress dashboard

---

## Stage 3: Opportunity

The user develops economic and professional readiness.

Tracks:
- Career Development
- Financial Literacy
- Community Integration

Goals:
- Employment readiness
- Financial stability
- Community engagement

Outputs:
- Opportunity Badge
- Career readiness score

---

## Stage 4: Integration

The user develops deeper understanding of American systems and culture.

Tracks:
- Cultural Integration & Community
- Citizenship Readiness

Goals:
- Civic knowledge
- Cultural understanding
- Community participation

Outputs:
- Integration Badge
- Citizenship readiness score

---

## Stage 5: Citizenship

The user prepares for citizenship requirements.

Tracks:
- Citizenship Readiness
- English Proficiency

Goals:
- Pass citizenship interview
- Pass citizenship exam

Outputs:
- Citizenship Preparedness Certification

---

## Stage 6: Legacy

The user becomes a mentor and contributor.

Goals:
- Help others
- Share experiences
- Strengthen community

Outputs:
- Legacy Badge
- Mentor Status

# The American Journey User Stories

## User Account System

### Story 1

As a user,

I want to create an account,

So that my progress can be saved.

---

### Story 2

As a user,

I want to log into my account,

So that I can continue my journey.

---

## Dashboard

### Story 3

As a user,

I want to see my overall readiness score,

So that I understand where I stand.

---

### Story 4

As a user,

I want to see recommended next actions,

So that I know what to do next.

---

## English Track

### Story 5

As a user,

I want to complete English lessons,

So that I can improve my communication skills.

---

### Story 6

As a user,

I want to track my English progress,

So that I can see improvement over time.

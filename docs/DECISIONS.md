# DECISIONS

## PURPOSE

This document records major product, architecture, and strategic decisions.

# DECISION LOG

## Decision 001

### Title

The American Journey Is A Success Platform

### Status

Accepted

### Reason

The platform's objective is to improve life outcomes rather than deliver educational content.

Education remains important but exists in service of success.

### Date

2026

Accepted

## Decision 006

### Title

Accepted

* Foundation

* Legacy

## Decision 012

### Title

GitHub Issue Driven Development

### Status

Accepted

### Reason

Features should move through a structured lifecycle:

Issue

→ Success Criteria

→ Implementation

→ Testing

→ Verification

→ Closure

This reduces scope drift and preserves project continuity.

2026

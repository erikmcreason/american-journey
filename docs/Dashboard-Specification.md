# Dashboard Specification

## Purpose

The Dashboard is the primary command center of The American Journey.

Every user should immediately understand:

1. Where they are.
2. How they are progressing.
3. What they should do next.

---

# Section 1: Welcome Header

Display:

Welcome, [First Name]

Journey Stage:

* Arrival
* Foundation
* Opportunity
* Integration
* Citizenship
* Legacy

---

# Section 2: Readiness Score

Display:

Overall Readiness Score

Example:

72%

Level:

Pathfinder

Display:

* Current Level
* Next Level
* Progress To Next Level

---

# Section 3: Recommended Next Action

Display:

Recommended Next Step

Example:

Complete English Lesson 3

Button:

Start Now

Purpose:

Eliminate uncertainty.

Users should always know what to do next.

---

# Section 4: Track Progress

Display all five tracks.

English & Communication

Financial Literacy & Opportunity

Citizenship Readiness

Administrative Readiness

Cultural Integration & Community

For each track display:

* Progress %
* Lessons Completed
* Current Level

---

# Section 5: Achievements

Display:

Recent Badges

Recent Milestones

Upcoming Unlocks

---

# Section 6: Quick Navigation

Buttons:

Dashboard

Tracks

Assessments

Achievements

Profile

---

# Mobile Considerations

Dashboard must function on:

* Mobile
* Tablet
* Desktop

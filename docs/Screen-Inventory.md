# The American Journey Screen Inventory

## MVP Screens

### Screen 1: Landing Page

Purpose:

Introduce The American Journey and encourage registration.

Key Elements:

- Mission
- Benefits
- Call To Action
- Sign Up
- Login

---

### Screen 2: Registration

Purpose:

Create a user account.

Key Elements:

- Name
- Email
- Password
- Country of Origin
- Immigration Status

---

### Screen 3: Onboarding Assessment

Purpose:

Determine user starting point.

Key Elements:

- English Assessment
- Financial Literacy Assessment
- Citizenship Readiness Assessment
- Administrative Readiness Assessment

---

### Screen 4: Journey Map

Purpose:

Provide users with a visual representation of their progression through The American Journey.

Key Elements:

- Current Stage
- Completed Stages
- Locked Stages
- Future Unlocks
- Milestones
- Rewards
- Recommended Path

Journey Stages:

- Arrival
- Foundation
- Opportunity
- Integration
- Citizenship
